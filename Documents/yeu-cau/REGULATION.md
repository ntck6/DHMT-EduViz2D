**⏰ Deadline:** Nộp vào ngày thi lý thuyết cuối kỳ.

## 1. Cấu trúc bản mềm (Tổ chức theo thư mục)

*   **1.1. Doc:** Chứa file báo cáo đồ án (file `.doc` + `.pdf`).
*   **1.2. BTLopNha:** Chứa file bài tập lớp-nhà (file `.doc` + `.pdf`).
*   **1.3. Slide:** Chứa file trình chiếu (file `.ppt` + `.pdf`). *Lưu ý: Nếu có video clip thì chép kèm theo, đính kèm font chữ.*
*   **1.4. Reference:** Danh sách các file `.pdf` và bản `.pdf` của các tài liệu đã dùng trong báo cáo, đường link tài liệu.
*   **1.5. Data:** Một số mẫu dữ liệu cần thiết để minh họa lý thuyết, đường link dữ liệu (tập dữ liệu mẫu, tập ảnh kết quả).
*   **1.6. Source code:** Chứa mã nguồn tham khảo hoặc tự tạo và chú thích mã nguồn, đường link tài liệu, source code, chương trình thực thi.
*   **1.7. Video clip:** Chứa các đoạn video nếu có liên quan đến đồ án.
*   **1.8. Personal Information:** Chứa thông tin cá nhân của nhóm cùng bảng phân công và thực hiện đồ án.
