# Xây dựng ứng dụng 2D (tĩnh và động) dựa vào HTML5 + WebGL hỗ trợ giáo dục

**Mục tiêu đồ án:** Trình bày cách sử dụng kết hợp HTML5 và WebGL để xây dựng một ứng dụng nền web hỗ trợ trực quan hóa kiến thức giáo dục (Toán học, Vật lý, Tin học). Ứng dụng khai thác sức mạnh của GPU thông qua WebGL để xử lý và hiển thị mượt mà các đối tượng đồ họa 2D cả ở trạng thái tĩnh và động.
